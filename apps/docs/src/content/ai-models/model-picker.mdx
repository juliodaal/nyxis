## Installation

```bash
pnpm add nyxis-ui
```

## Usage

```tsx
import { ModelPicker } from 'nyxis-ui';
// or, for stricter tree-shaking:
// import { ModelPicker } from 'nyxis-ui/model-picker';

<ModelPicker
  value={modelId}
  onValueChange={(id) => setModelId(id)}
  requireCapabilities={['vision']}
/>;
```
