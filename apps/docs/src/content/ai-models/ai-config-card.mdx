## Installation

```bash
pnpm add nyxis-ui
```

## Usage

```tsx
import { AIConfigCard } from 'nyxis-ui';
// or, for stricter tree-shaking:
// import { AIConfigCard } from 'nyxis-ui/ai-config-card';

<AIConfigCard
  defaultConfig={{
    provider: 'anthropic',
    model: 'claude-sonnet-4-5',
    temperature: 0.7,
    maxTokens: 1024,
  }}
  onConfigChange={persist}
/>;
```
