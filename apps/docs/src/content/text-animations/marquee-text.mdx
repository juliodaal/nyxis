## Installation

```bash
pnpm add nyxis-ui
```

## Usage

```tsx
import { MarqueeText } from 'nyxis-ui';
// or, for stricter tree-shaking:
// import { MarqueeText } from 'nyxis-ui/marquee-text';

<MarqueeText speed={28}>
  {logos.map((logo) => (
    <span key={logo}>{logo}</span>
  ))}
</MarqueeText>;
```
