**Nyxis** is a toolkit for building AI products. It is built on top of
[shadcn/ui](https://ui.shadcn.com) and distributes components through the
shadcn CLI: every piece is copy-paste source code that lands in your repo
and is yours to edit.

## What you get

- **AI-first components** for chat, agents, RAG, MCP, tools, multimodal,
  prompts, evaluation, and skills — patterns the community keeps
  re-implementing.
- **Backend recipes** — route handlers, server helpers, schemas — that
  give you a working AI server in minutes. Provider-agnostic.
- **`@nyxis/core`** — a tiny npm package holding shared types, the
  provider adapter, and the event bus. The only thing that needs to be
  versioned.
- **Editable everywhere** — every component is plain Tailwind + Radix.
  Change a class, add a prop, rip something out. There is no abstraction
  to fight.
- **Provider-agnostic** — Anthropic, OpenAI, Google, Mistral, Ollama out
  of the box. Add your own with a single file.

## Distribution model

Nyxis ships as **three layers**, none subordinate to the others:

1. **`@nyxis/core`** — npm package. Types, adapter, event bus.
2. **Frontend registry** — `npx shadcn add @nyxis/<component>`. UI you own.
3. **Backend registry** — `npx shadcn add @nyxis/<recipe>`. Servers you own.

You can install only the backend, only the frontend, or both. Future:
an MCP server exposes the catalog to Claude Code, Cursor, and Windsurf so
the assistant can scaffold an entire AI app from prompts.

## How the docs are organised

- **Getting started** — installation and theming.
- **Components** — base UI primitives (re-exported from shadcn/ui for
  convenience).
- **AI categories** — chat, reasoning, tools, MCP, agents, multimodal,
  prompts, RAG, skills.
- **AI animations** — motion primitives specific to AI products
  (sparkle fields, halo borders, neural backgrounds).
- **Domain patterns** — purpose-built components for AI workflows.

Use **⌘K** (or **Ctrl K**) at any time to jump to a component.
