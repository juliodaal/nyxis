**Nyxis** is a React component library purpose-built for the next generation
of AI-powered SaaS products. It pairs accessible Radix UI primitives with
high-quality GSAP animations and a strict five-mode theming system, then
ships them as a real, installable npm package — not a copy-paste snippet
collection.

## Why Nyxis exists

Every AI-product UI re-invents the same building blocks: a chat bubble with
streaming text, a citation card, a confidence badge, a file dropzone with PDF
previews, a KPI card with a sparkline. Nyxis is the consolidation of those
patterns — designed once, accessible, themed correctly, and reused across an
entire SaaS portfolio.

## What you get

- **52+ components** across four categories: text animations, base UI, effect
  animations, and domain-specific patterns mapped to real AI workflows.
- **Five themes**: light, dark, dim, high contrast, and system, all driven by
  a single `data-theme` attribute and synchronized across pages, islands, and
  even Storybook.
- **Accessibility by default** through Radix UI primitives, WCAG-aware tokens,
  and `axe-core` enforcement in CI.
- **Production-grade animations** with GSAP and ScrollTrigger, every effect
  honoring `prefers-reduced-motion`.
- **Server-component friendly** — `"use client"` directives are preserved
  through the build, so Next.js App Router integrations just work.
- **Tree-shakeable** through per-component subpath exports.

## How the docs are organised

- **Getting started** — installation, theming, and security baseline.
- **Text animations** — GSAP-powered text effects.
- **Components** — base UI primitives.
- **Animations** — effect components and animated backgrounds.
- **Domain patterns** — components designed for specific AI workflows
  (chat, citations, audit logs, KPIs, ...).

Use **⌘K** (or **Ctrl K**) at any time to jump to a component.
