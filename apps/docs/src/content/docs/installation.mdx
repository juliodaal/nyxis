Nyxis ships through a [shadcn-compatible registry](./registry). You
install components and recipes with the standard `shadcn` CLI; they
land as plain TypeScript files in your repo and are yours to edit.

## Requirements

- **React 18 or 19**
- **Tailwind CSS v4**
- **shadcn CLI** (already in the shadcn ecosystem — installed on demand
  via `npx`)

## 1. Bootstrap your project with shadcn

If you don't have shadcn yet, run its initialiser. It writes
`components.json`, `lib/utils.ts`, the design tokens, and the
TypeScript path alias config Nyxis components rely on:

```bash
npx shadcn@latest init
```

## 2. Install the runtime

The only npm package Nyxis ships is **`@nyxis/core`**: shared types,
the provider adapter, the event bus, and the React hooks. Components
and backend recipes do not live in npm — they're copy-paste.

```bash
pnpm add @nyxis/core
```

## 3. Install the theme system

Nyxis includes a five-mode theme runtime (`light`, `dark`, `dim`,
`high-contrast`, `system`). It's a tiny separate package so the design
tokens stay versioned:

```bash
pnpm add nyxis-ui
```

In your global CSS:

```css
@import 'tailwindcss';
@import 'nyxis-ui/styles.css';
```

In your root layout (FOUC-safe inline script):

```tsx title="app/layout.tsx (Next.js)"
import { getThemeScript } from 'nyxis-ui/theme';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en" suppressHydrationWarning>
      <head>
        <script dangerouslySetInnerHTML={{ __html: getThemeScript() }} suppressHydrationWarning />
      </head>
      <body>{children}</body>
    </html>
  );
}
```

The theme switcher itself is a registry item:

```bash
npx shadcn@latest add https://nyxisai.vercel.app/r/theme-toggle.json
```

## 4. Install components

Pick what you need from the [registry catalog](./registry) and install
each with the shadcn CLI:

```bash
npx shadcn@latest add https://nyxisai.vercel.app/r/chat-message.json
npx shadcn@latest add https://nyxisai.vercel.app/r/agent-roster.json
npx shadcn@latest add https://nyxisai.vercel.app/r/rag-pipeline.json
```

The CLI:

- Resolves cascading registry dependencies (e.g. `agent-roster` pulls
  `agent-card`, which pulls `agent-status-badge`, which pulls `utils`).
- Installs the npm `dependencies` declared by each item (`@nyxis/core`,
  `lucide-react`, `framer-motion`, etc.).
- Drops source files into `src/components/nyxis/<name>.tsx` and
  `src/lib/utils.ts`.

Then import them as local modules:

```tsx
'use client';

import { ChatMessage } from '@/components/nyxis/chat-message';
import { ChatThread } from '@/components/nyxis/chat-thread';
import { useChat } from '@nyxis/core';

export function Chat() {
  const { messages, append } = useChat({ api: '/api/chat' });
  return (
    <ChatThread messages={messages}>
      {messages.map((m) => (
        <ChatMessage key={m.id} role={m.role}>
          {m.content}
        </ChatMessage>
      ))}
    </ChatThread>
  );
}
```

## Editing what you installed

Every file the CLI writes is plain TypeScript and plain Tailwind. There
is no theming abstraction to fight. Change a class, drop a prop, swap a
component — it is your file now.
