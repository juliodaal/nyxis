## Requirements

Nyxis is built on top of [shadcn/ui](https://ui.shadcn.com) and uses the
shadcn CLI to copy components into your project. You need:

- **React 18 or 19**
- **Tailwind CSS v4**
- **shadcn/ui CLI** (already in the shadcn ecosystem)

```bash
pnpm add @nyxis/core
```

`@nyxis/core` is the only npm package — it holds shared types, the AI
provider adapter, and the event bus. Components and backend recipes are
copy-paste via the shadcn CLI.

## 1. Configure Tailwind

In your global CSS (e.g. `app/globals.css` for Next.js, `src/index.css`
for Vite), pull in Tailwind:

```css
@import 'tailwindcss';
```

Tailwind v4 discovers everything from CSS — no `tailwind.config.js`
needed.

## 2. Install a frontend component

```bash
npx shadcn@latest add https://nyxis.vercel.app/r/confidence-badge.json
```

The file lands in `src/components/nyxis/confidence-badge.tsx` along with
its registry dependencies (e.g. `lib/utils.ts`). You own it — edit the
markup, the Tailwind classes, the variants. There is no theming system
to fight.

See the [Registry guide](./registry) for how the catalog works, how to
install many components at once, and the URL pattern for every item.

## 3. Install a backend recipe

> Backend recipes ship in **Phase 2** of the roadmap (see
> [Introduction](./introduction)). Until then, route handlers can be
> assembled by hand using `@nyxis/core` — `createModel` from
> `@nyxis/core/server` returns a Vercel-AI-SDK-compatible model that
> you pass to `streamText`.

## 4. Use it

```tsx
'use client';
import { ChatMessage } from '@/components/nyxis/chat-message';
import { useChat } from '@nyxis/core';

export function Chat() {
  const { messages, append } = useChat({ api: '/api/chat' });
  return messages.map((m) => (
    <ChatMessage key={m.id} role={m.role}>
      {m.content}
    </ChatMessage>
  ));
}
```
