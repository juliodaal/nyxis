## Installation

```bash
pnpm add nyxis-ui
```

## Usage

```tsx
import { Popover } from 'nyxis-ui';
// or, for stricter tree-shaking:
// import { Popover } from 'nyxis-ui/popover';

<Popover>
  <PopoverTrigger asChild>
    <Button>Open</Button>
  </PopoverTrigger>
  <PopoverContent>Filters go here.</PopoverContent>
</Popover>;
```
