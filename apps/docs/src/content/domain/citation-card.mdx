## Installation

```bash
pnpm add nyxis-ui
```

## Usage

```tsx
import { CitationCard } from 'nyxis-ui';
// or, for stricter tree-shaking:
// import { CitationCard } from 'nyxis-ui/citation-card';

<CitationCard
  rank={1}
  source="Employee handbook"
  locator="§4.2"
  href="#"
  snippet="The fiscal year ends on March 31."
/>;
```
