## Usage

```tsx
import { FileDropzone } from 'nyxis-ui';
// or, for stricter tree-shaking:
// import { FileDropzone } from 'nyxis-ui/file-dropzone';

<FileDropzone
  accept="application/pdf,image/*"
  maxSize={25 * 1024 * 1024}
  onFilesChange={(files) => upload(files)}
/>;
```
