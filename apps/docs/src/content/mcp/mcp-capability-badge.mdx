## Installation

```bash
pnpm add nyxis-ui
```

## Usage

```tsx
import { MCPCapabilityBadge } from 'nyxis-ui';

<MCPCapabilityBadge capability="tools" />
<MCPCapabilityBadge capability="resources" compact />
```

## Capabilities

Mirrors the MCP spec exactly — pass any of `tools`, `prompts`, `resources`, `sampling`, `roots`, or `logging`. Icons:

| Capability  | Icon          |
| ----------- | ------------- |
| `tools`     | gear          |
| `prompts`   | speech bubble |
| `resources` | document      |
| `sampling`  | sparkle       |
| `roots`     | folder tree   |
| `logging`   | scroll        |

The `enabled={false}` variant renders muted — useful when surfacing a capability the _server_ advertises but the _client_ has disabled.
