## Installation

```bash
pnpm add nyxis-ui
```

## Usage

```tsx
import { VectorSearchInput } from 'nyxis-ui';

<VectorSearchInput
  defaultValue="when does the fiscal year end?"
  onSubmit={(query, { topK, threshold, reranker }) => {
    runRetriever({ query, topK, threshold, reranker });
  }}
/>;
```

## Anatomy

- Search input with leading icon (spinner while `loading`).
- `top-K` slider (default range `[1, 20]`).
- Similarity-threshold slider `0..1`.
- Reranker toggle.
- Submit fires `onSubmit(query, options)` — Enter in the input also submits.
