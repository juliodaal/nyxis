## Installation

```bash
pnpm add nyxis-ui
```

## Usage

```tsx
import { TypingIndicator } from 'nyxis-ui';

{
  isStreaming && <TypingIndicator label="Assistant is thinking" />;
}
```

## Variants

- `subtle` — three dots inline with the surrounding text.
- `bubble` — a card-like pill, suited for empty assistant turns.
