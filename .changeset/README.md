# Changesets

Hello and welcome! This folder has been automatically generated by
`@changesets/cli`. It manages changes to packages in this monorepo.

## How to add a changeset

```bash
pnpm changeset
```

The CLI will ask you which packages changed, the bump type (major / minor /
patch), and a summary. The summary becomes a line in the changelog.

When the changeset PR lands on `main`, the release workflow either opens a
"Version Packages" PR (which bumps versions and updates changelogs) or, if that
PR has already been merged, publishes the new versions to npm with provenance.

See [the Changesets docs](https://github.com/changesets/changesets) for details.
